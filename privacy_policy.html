欢迎您使用「工具猫」（以下简称“本应用”），本应用由个人开发者独立开发并运营。我们严格遵守《中华人民共和国网络安全法》《中华人民共和国个人信息保护法》等相关法律法规，致力于保护您的个人信息和隐私安全。您使用本应用即表示同意本隐私政策的全部内容，如您不同意，请立即停止使用本应用。

一、适用范围

本隐私政策适用于您使用本应用提供的所有服务，包括但不限于文字识别、语言翻译、本地数据备份与存储、文件选择、存储位置自定义等功能。本政策仅规范本应用及直接集成的第三方SDK的信息处理行为，第三方SDK的具体信息处理规则以其官方合规说明为准。

二、我们收集和使用的个人信息及应用权限说明

2.1 必要收集的设备基础信息

为保障本应用基础功能正常运行、进行安全校验、防止功能滥用并优化服务体验，我们会收集以下必要信息：设备标识（如Android ID）、设备型号、操作系统版本、网络状态（Wi-Fi/移动网络）、应用崩溃日志等。上述信息仅用于应用功能稳定运行和安全保障，不会用于其他无关用途。

2.2 应用申请的系统权限及用途

本应用为单机工具类应用，所有用户数据均保存在本地设备中。本应用会根据功能需求申请以下系统权限，权限使用规则及场景如下：

  • 基础必要权限（安装时默认获取，不可拒绝）：
    • 网络权限（INTERNET）：用于加载广告、下载Google ML Kit语言模型、获取翻译与识别能力；注：若关闭广告个性化推荐开关，重启应用后将不再加载广告，仅保留ML Kit模型下载的网络请求；
    • 网络状态权限（ACCESS_NETWORK_STATE）：用于检测网络状态，优化广告加载与模型下载；
    • 唤醒锁权限（WAKE_LOCK）：仅在广告加载/ML Kit模型下载时临时保持后台运行，完成后立即释放，不常驻占用系统资源；
    • OpenGL ES 2.0特性（glEsVersion=0x00020000）：为广告SDK渲染广告内容的必要系统特性，无隐私数据收集行为；
  • 广告SDK相关权限（需用户主动授权，拒绝不影响应用核心功能）：
    广告个性化推荐开关说明：您可在「我的」->「开关设置」->「广告个性化推荐」中操作该开关：
    ▶ 关闭开关：重启应用后，本应用将不再初始化口袋工厂广告SDK，不会加载任何广告，也不会触发广告SDK相关的权限请求；
    ▶ 开启开关：重启应用后，将正常初始化广告SDK，广告可正常投放，相关权限仅在SDK初始化后按需调用。
    • 电话权限（READ_PHONE_STATE）：仅由口袋工厂广告聚合SDK调用，用于获取设备标识（如Android ID）以保障广告统计准确性，不会读取电话号码、通话记录、IMEI/MEID等敏感信息；关闭广告开关后，该权限不会被调用；
    • 读取应用列表权限（QUERY_ALL_PACKAGES / GET_TASKS）：QUERY_ALL_PACKAGES用于广告推荐、体验广告相关App减免时长等服务，GET_TASKS用于检测应用前台/后台状态以优化广告展示时机，不会收集应用使用行为、应用内数据等信息；关闭广告开关后，该权限不会被调用；
    • 精确位置权限（ACCESS_FINE_LOCATION）：仅用于广告SDK精准推荐广告，可随时在系统设置中关闭，不影响应用核心功能；关闭广告开关后，该权限不会被调用；
    • 安装应用权限（REQUEST_INSTALL_PACKAGES）：仅用于广告体验中“下载并安装App减免时长”的场景，用户可拒绝授权，拒绝后仅无法参与该广告体验活动，不影响核心功能；关闭广告开关后，该权限不会被调用；
  • 功能可选权限（需用户主动操作时调用，拒绝不影响核心功能）：
    • 存储权限（READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE / MANAGE_EXTERNAL_STORAGE）：仅在用户主动操作时调用，用于文件及文件夹的选择和猫币及签到数据的本地持久化备份、存储与恢复；
    • 相机权限（CAMERA）及相机自动对焦特性（android.hardware.camera.autofocus）：仅在用户主动操作时调用，用于拍摄图片并进行文字识别、本地头像更换、图片颜色提取；自动对焦特性仅在拍摄时启用，提升拍摄清晰度，随相机权限授权生效；
    • 图片权限（READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE）：仅在用户主动操作时调用，用于图片选择并进行文字识别、本地头像更换、图片颜色提取、图片拼接长图、图片识别表格、图片转pdf、图片转word、图片合成gif、gif播放器；
    • 视频权限（READ_MEDIA_VIDEO / READ_EXTERNAL_STORAGE）：仅在用户主动操作时调用，用于视频选择并进行视频编码、压缩；
    • 音频权限（READ_MEDIA_AUDIO / READ_EXTERNAL_STORAGE）：仅在用户主动操作时调用，用于音频选择并进行计时器的铃声更换；
    • 麦克风权限（RECORD_AUDIO）：仅在用户主动操作时调用，用于音频录制并选择进行计时器的铃声更换；
    • 相机/视频拍摄意图（IMAGE_CAPTURE/ACTION_VIDEO_CAPTURE）：应用仅通过系统接口唤起设备自带的相机App，不会直接访问相机硬件，也不会收集拍摄的图片/视频数据，仅用于用户主动拍摄识别的场景；

2.3 Google ML Kit SDK 数据处理详细说明

本应用集成Google ML Kit（com.google.mlkit:translate 等功能）实现文字识别、语言翻译、语言识别功能，其数据处理严格遵循Google官方隐私政策及Google Play数据安全披露规则，具体说明如下：

2.3.1 数据收集类型（仅用于诊断和使用情况分析）

  • 通用收集数据（所有ML Kit功能）：
    • 设备信息：制造商、型号、操作系统版本、build、可用的机器学习硬件加速器；
    • 应用信息：软件包名称、应用版本；
    • 标识符：不用于唯一标识用户/设备的每次安装标识符（精简版/捆绑功能）；用户/设备标识符（生成式AI功能，仅用于诊断分析）；
    • 效果指标：性能指标（如延迟时间）、API配置（如图片格式/分辨率）、特征输入/输出大小、功能版本；
    • 活动数据：事件类型（功能初始化、模型下载、检测、资源释放）、错误代码；
  • 翻译功能专属收集数据：已配置的源语言和目标语言（仅用于诊断和使用情况分析）；

2.3.2 数据加密与共享规则

  • 数据加密：ML Kit对传输中的所有收集数据使用HTTPS加密；
  • 数据共享：ML Kit不会将收集的上述数据传输给任何第三方；

2.3.3 关联Firebase组件说明

  • ML Kit使用Firebase远程配置和Firebase安装进行远程配置诊断，相关数据处理遵循Firebase官方隐私政策；
  • Firebase组件仅用于ML Kit功能的调试、维护和优化，不会收集用户个人身份信息。

2.3.4 核心数据处理规则

  • 文字识别、翻译的输入数据（图片、文本）及处理结果全部在您的设备本地完成，不会上传至Google服务器或开发者服务器；
  • 首次使用ML Kit功能时，会从Google服务器下载对应的语言模型文件（存储于设备本地），后续可能不定期请求bug修复、模型更新、硬件加速器兼容性信息；
  • 所有收集的诊断数据均为匿名化处理，不会用于唯一标识用户或设备。

四、信息存储与安全保护

4.1 存储规则

本应用为纯本地工具，所有用户数据（包括使用记录、卡包信息、抽奖记录、配置信息等）仅存储在您的设备本地，未上传至任何服务器。

  • 常规数据：长期存储于本地，直至您卸载应用或清除应用数据；
  • 备份数据：若开启“数据备份”功能，数据会备份至设备「下载文件夹下的.a75bc6d747d4b72f68b71ed9537cce29隐藏文件夹」，卸载应用不会自动删除，需手动清除或关闭备份功能；
  • 广告开关状态：本地存储，卸载应用后恢复为默认开启状态；
  • ML Kit模型文件：存储于本地，可在应用内「我的」->「我的语言模型」中手动删除。

4.2 安全保护措施

我们采用本地加密、数据校验等方式保护您的本地数据安全，防止信息丢失、损坏、篡改。
